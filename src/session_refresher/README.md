# session_refresher

Контур автообновления Firefox-сессии для профиля `~/firefox_profile`.

Назначение:
- периодически запускать Firefox в легковесном GUI-стеке (`Xvfb`),
- открыть набор целевых сайтов,
- сохранить обновления сессии обратно в профиль.

Файлы:
- `refresh_session.sh` - скрипт, который запускается внутри docker-контейнера.
