# DB

Эта папка предназначена для локальных database artifacts проекта.

Что здесь может находиться:

- локальный `bot.db`;
- вспомогательные файлы БД для разработки и диагностики;
- временные database artifacts, созданные во время локальных прогонов.

Правила:

- содержимое папки считается локальным runtime-state, а не частью tracked source of truth;
- файлы БД не должны попадать в git;
- tracked в репозитории остается этот `README.md`.
