# Runtime

Эта папка хранит локальные runtime artifacts, которые создаются обработчиками и media gateways во время работы.

Что здесь может находиться:

- временные загруженные медиафайлы;
- промежуточные результаты обработки по source handlers;
- служебные подпапки для cleanup и диагностики локальных прогонов.

Правила:

- папка не является policy- или product-layer;
- runtime artifacts не должны коммититься в git;
- каждый handler или gateway должен очищать свои временные файлы после использования;
- tracked в репозитории остается только этот `README.md`.
