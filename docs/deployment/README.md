# deployment

Документы по деплою, CI/CD и эксплуатационным правилам.

Ключевые документы:
- `branch-policy.md` - политика веток и контуров.
- `cicd.md` - поведение workflow.
- `cookies-policy.md` - правила cookies-контура (extractor + session-refresher).
- `cookies-host-setup.md` - подготовка Ubuntu-хоста под cookies-контур.
- `session-refresh-manual.md` - ручной сценарий восстановления профиля и запуска автообновления сессии.
- `cron.md` - cron-подход и операционные заметки.
