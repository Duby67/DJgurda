# Cron

На сервере используется `cron` для периодических запусков session-refresher.

Базовый подход:
- CI/CD заранее доставляет свежий образ `cookies-refresh` на сервер (`docker pull`).
- CI/CD автоматически копирует runtime-файлы в `~/cookies/runtime`.
- по расписанию запускается `~/cookies/runtime/run_session_refresher.sh`.
- контейнер запускается от UID/GID пользователя хоста, поэтому профиль не блокируется root-владельцем.
- логирование рекомендуется вести в `$HOME/logs/session_refresher.log`.

Важно: настройка `crontab` выполняется вручную, после того как вы подтвердите корректность ручного запуска.
