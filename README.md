# DJgurda

Telegram-бот для удобного переноса медиа по ссылке в чат. Новая реализация начинается
с каркаса [AgentFleex](https://github.com/Duby67/AgentFleex/tree/c91a48f08cc011d89d3ddadf7fbe17a3a07d018b).
В этой версии репозитория пока нет кода бота, зависимостей и автоматического развёртывания.

## Границы новой версии

- Основной сценарий: ссылка → получение контента → отправка в Telegram-чат.
- База данных хранит конфигурацию чатов.
- Статистика пока не реализуется; данные из legacy не переносятся.
- Redis, внешний брокер задач и веб-фреймворк не используются.
- Дополнительное прикладное шифрование не предусматривается; секреты передаются через окружение.
- Репозиторий предназначен для публичного размещения.

## Ветки

| Ветка | Назначение |
| --- | --- |
| `main` | Production: целевая ветка для готовых обновлений и будущего production deploy |
| `integration` | Накопление изменений новой версии; обновления попадают в `main` через PR |
| `legacy` | Сохранённая предыдущая реализация на коммите `4f1966e5dc3aa91fbf133666005434ddb655c48d` |

Первый PR из `integration` заменяет старое содержимое каркасом. История Git сохраняется,
чтобы ветки можно было сравнивать и объединять обычным PR. Старые deploy-workflows
удаляются вместе с legacy-кодом; production deploy новой версии нужно реализовать
вместе с приложением. `integration` не развёртывается в production.
