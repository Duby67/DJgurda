# DJgurda

Telegram-бот для переноса медиа по ссылке в чат.

Текущая версия при запуске отправляет администраторам уведомление с версией пакета и работает
через long polling без ответов на сообщения. Обработка медиа не реализована.

Сборка, CI/CD и ресурсы сервера: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

## Границы

- Сценарий: ссылка → получение контента → отправка в Telegram-чат.
- База данных хранит конфигурацию чатов.
- Статистика не ведётся; данные из legacy не переносятся.
- Без Redis, внешнего брокера задач и веб-фреймворка.
- Без прикладного шифрования; секреты передаются через окружение.
- Репозиторий публичный.

## Конфигурация

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | Токен Telegram-бота; отдельный для каждого окружения |
| `ADMIN_IDS` | Непустой JSON-массив ID администраторов, например `[123456789]` |
| `APP_ENV` | `development` (по умолчанию) или `production` |
| `LOG_LEVEL` | `DEBUG`, `INFO` (по умолчанию), `WARNING`, `ERROR`, `CRITICAL` |

Переменные процесса имеют приоритет над `.env`. Администратор должен заранее нажать Start в чате
с ботом, иначе запуск завершится ошибкой.

## Ветки

| Ветка | Назначение |
| --- | --- |
| `main` | Production |
| `development` | Интеграция изменений; в `main` попадает через PR |
| `legacy` | Предыдущая реализация |

Маршрут: ветка от `development` → PR в `development` → PR в `main`.
