# DJgurda

Telegram-бот для переноса медиа по ссылке в чат.

При запуске и выключении бот уведомляет администраторов и работает через long polling.
В активном чате он классифицирует ссылки по источнику и типу, включая зеркала вроде
kkinstagram.com. Бот скачивает и отправляет в чат вместо исходного сообщения видео, Shorts и клипы
YouTube, видео TikTok, Reels Instagram и треки Яндекс Музыки; остальные типы пока отвечают
заглушкой. Чтобы удалять сообщения в группе, боту нужны права администратора на удаление.

| Команда | Действие |
| --- | --- |
| `/start` | Включить бота в чате |
| `/stop` | Приостановить бота в чате |
| `/status` | Статус бота в чате и версия |
| `/saymyname имя` | Имя в подписях в этом чате; без имени — сброс |
| `/help` | Команды и поддерживаемые источники |

Продуктовые решения: [docs/PRODUCT.md](docs/PRODUCT.md). Запланированное: [docs/TODO.md](docs/TODO.md).
Сборка, CI/CD и ресурсы сервера: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

## Границы

- Сценарий: ссылка → получение контента → отправка в Telegram-чат.
- База данных хранит конфигурацию чатов.
- Статистика не ведётся; данные из legacy не переносятся.
- Без Redis, внешнего брокера задач и веб-фреймворка.
- Без прикладного шифрования; секреты передаются через окружение.
- Репозиторий публичный.

## Конфигурация

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | Токен Telegram-бота; отдельный для каждого окружения |
| `ADMIN_IDS` | Непустой JSON-массив ID администраторов, например `[123456789]` |
| `APP_ENV` | `development` (по умолчанию) или `production` |
| `DATABASE_PATH` | Файл SQLite; в Compose задан как `/data/djgurda.sqlite3` |
| `YANDEX_MUSIC_TOKEN` | Необязательный токен Яндекс Музыки; без него треки не скачиваются |
| `WORK_DIR` | Каталог временных загрузок; в Compose задан как `/data/work` |
| `LOG_LEVEL` | `DEBUG`, `INFO` (по умолчанию), `WARNING`, `ERROR`, `CRITICAL` |

Переменные процесса имеют приоритет над `.env`. Администратор должен заранее нажать Start в чате
с ботом, иначе запуск завершится ошибкой.

## Ветки

| `main` | Production |
