# AGENTS: Контекст агентной работы

Этот файл задает базовые правила для агентов, работающих в репозитории.

## Цель репозитория

Подготовка и развитие Telegram-бота на Python с понятной структурой, воспроизводимой средой и документируемыми решениями.

## Базовые правила

- Перед изменениями читать `README.md`, `ARCHITECTURE.md` и локальные `AGENTS.md` в затронутых папках.
- Не удалять и не перезаписывать пользовательские изменения без явного запроса.
- Поддерживать документы в актуальном состоянии при структурных изменениях.
- Новые директории сопровождать короткими `README.md` и `AGENTS.md`.

## Стандарты на старте

- Python-интерпретатор: `Python 3.11`.
- Виртуальное окружение: `venv`.
- Базовые зависимости: `requirements.txt`.
