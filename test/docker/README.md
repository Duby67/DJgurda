# test/docker

Каталог для локальных тестов Docker-образов и compose-контуров.

Цель - проверять сборку и runtime-поведение локально, без ожидания
публикации образа и доставки runtime-файлов на сервер.

Доступные стенды:

- `cookies-session-refresher/` - локальный прогон
  cookies-session-refresher образа на профиле из `local/`.
